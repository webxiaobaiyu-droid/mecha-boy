# Third-party assets

The authoritative, per-file provenance and license ledger is
[`docs/ASSET_LICENSES.md`](docs/ASSET_LICENSES.md). It records authors,
licenses, source pages, download URLs, upstream archive hashes, local file
hashes, transformations, and required release attributions.

The project does not contain art extracted from commercial games. New work
must use original assets or assets with a verified entry in that ledger.
